# ClaimShield — Milestone 1

Health insurance claim management system (console application).

 Nguyen Ba Nam — S3974998
**Requires:** JDK 17 or newer 

## How to compile and run

From this folder (the folder containing `src` and `data`):

```bash
javac -d out $(find src -name "*.java")     # Linux / macOS
java -cp out claimshield.ClaimShieldApp
```

On Windows:

```bat
dir /s /B src\*.java > sources.txt
javac -d out @sources.txt
java -cp out claimshield.ClaimShieldApp
```

The program reads the data files from the `data` folder relative to the working
directory, so run it from this folder. A different folder can be passed as the
first argument:

```bash
java -cp out claimshield.ClaimShieldApp /path/to/other-data
```

In an IDE, set the working directory of the run configuration to this folder and
run `claimshield.ClaimShieldApp`.

## Project layout

```
src/claimshield/ClaimShieldApp.java        entry point, wires the layers
src/claimshield/model/                     Customer, InsuranceCard, Claim
src/claimshield/manager/ClaimManager.java  in-memory data layer + business rules
src/claimshield/io/                        FileStorage, RecordMapper
src/claimshield/util/                      Validator, IdGenerator
src/claimshield/ui/                        ConsoleMenu, InputReader
data/customers.txt                         20 sample customers
data/insurance_cards.txt                   20 sample insurance cards
data/claims.txt                            20 sample claims
```

## Data file format

One record per line, fields separated by `|`. Lines starting with `#` are
comments. Dates are ISO-8601. Documents inside a claim are joined with `;`.

```
customers.txt        id|fullName|customerType|parentPolicyHolderId
insurance_cards.txt  cardNumber|cardHolderId|policyOwnerId|expirationDate
claims.txt           id|claimDate|insuredPersonId|cardNumber|examDate|documents|claimAmount|status
```

`parentPolicyHolderId` is the literal `null` for a policy holder.

## Using the console

- The main menu offers Customers, Insurance Cards, Claims and Save and Exit.
- Inside any sub menu, `0` goes back.
- Typing `cancel` at any prompt aborts the current operation and changes nothing.
- Ids and card numbers can be auto-generated by answering `y` when offered.
- Choosing Save and Exit writes every record back to the three data files.

## Notes

- Records are only written to disk on Save and Exit. The save writes temporary
  files first and swaps them in only after all three were written, so an
  interrupted save cannot leave a half written data file behind.
- A malformed line in a data file is reported with its file name, line number and
  reason, then skipped; the program still starts.
